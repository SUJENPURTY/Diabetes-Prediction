# Lab-Flask: Diabetes Prediction App

A simple **Flask web application** to predict whether a person is diabetic based on their health parameters.

---

## 🚀 How to Run

1. Clone the repository and navigate to the project folder.  
2. Run the Flask application:

```bash
python app.py

```
open a browser and go to:

http://127.0.0.1:5000/predictdata
